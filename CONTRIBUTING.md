## How Can I Contribute?

### Reporting Bugs

- **Search** existing [Issues](https://github.com/your-username/anti-social-network/issues) to avoid duplicates.
- If you find a new bug, [open an issue](https://github.com/your-username/anti-social-network/issues/new/choose) with:
  - A clear title and description.
  - Steps to reproduce.
  - Your browser version and OS.

### Suggesting Enhancements

- Open an issue with the `enhancement` label.
- Describe the feature and why it aligns with the project’s anti‑mainstream philosophy.

### Pull Requests

1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-thing`).
3. Make your changes.
4. Commit with a descriptive message.
5. Push to your fork and open a PR against `main`.
