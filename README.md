## ✨ Why Anti Social?

Mainstream social media is a digital prison – censorship, data mining, and algorithmic manipulation. **Anti Social Network** is a middle finger to that system. A collection of raw, unfiltered apps designed for people who value freedom of speech over conformity.

> **5 apps** • **Desktop & Android** • **Cross‑sync** • **Zero censorship** • **Privacy first**

## 🖥️ Features

### 🔹 One Dashboard
Access all apps from a single, glitch‑themed interface. Switch between Shroud, Drift, Trade, Pulse, and Bloom without juggling tabs.

### 🔹 Local Credential Storage
All tokens and preferences are stored in your browser's `localStorage` – they never touch our servers. You stay in control.

### 🔹 Cross‑Platform
Each app is available for:
- **Desktop** (Windows)  
- **Android** (APK)  
- **Web Browser** (live versions)

### 🔹 Built‑in Access Gates
Some apps require a simple challenge to enter – a ZIP code, a daily puzzle, or an embed challenge – ensuring only curious minds get in.

### 🔹 Subscription Support
Help keep the network alive with a PayPal subscription – you get early access and exclusive features.

---

## 📦 Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (landing page) – each app has its own stack
- **Backend**: Node.js / Express (for Trade & Pulse), decentralised (Drift)
- **Storage**: Browser `localStorage`, plus optional cloud sync
- **Payments**: PayPal subscription integration
