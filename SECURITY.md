# Security Policy

## Supported Versions

We actively support the latest stable release of the Anti Social Network landing page and apps.

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |
| < 0.1   | ❌        |

## Reporting a Vulnerability

We take security seriously – especially regarding credential storage (`localStorage`) and API keys.

If you discover a vulnerability, **do not open a public issue**. Instead, email us at **[INSERT SECURITY EMAIL]** or use GitHub’s **Private vulnerability reporting** feature.

Please include:
- A detailed description.
- Steps to reproduce.
- Potential impact.

We will respond within 48 hours and keep you updated on our progress.

Thank you for helping keep the network safe.
